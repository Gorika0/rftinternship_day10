# rftinternship_day10
This project reads a log file and analyzes different types of log messages like:
INFO
WARNING
ERROR
It helps in understanding how log analysis works in real-world applications.

#Features:
Read and analyze log files
Count total log entries
Count ERROR messages
Count WARNING messages
Count INFO messages
Display summary report
Beginner-friendly Python code
